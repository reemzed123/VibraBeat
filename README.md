# VibraBeat — Android prototype

אפליקציית Android כהה לזיהוי פעימות בס בזמן אמת ולהפעלת רטט בעוצמה משתנה, עם הגבלת עוצמה ידנית.

## מה כלול
- בחירה בין לכידת שמע פנימי לבין מיקרופון.
- ניתוח בזמן אמת של תחום תדרים משוער 45–180Hz.
- זיהוי פעימות עם סף רגישות מתכוונן וזמן חסימה קצר למניעת רטט רציף.
- רטט קצר שעוצמתו נגזרת מעוצמת האות, ומוגבלת על ידי המחוון.
- ממשק כהה, ללא ספריות צד שלישי.

## מגבלות אב-טיפוס
- נדרש Android 10 ומעלה; הפרויקט מכוון ל-Android 14 ומעלה בפועל.
- לכידת שמע פנימי תלויה בהרשאת MediaProjection ובכך שאפליקציית המקור מאפשרת לכידת שמע. חלק מאפליקציות הסטרימינג חוסמות זאת.
- בשלב זה הזיהוי פועל כשהמסך של VibraBeat פתוח. אין עדיין שירות רקע קבוע.
- ניתוח הבס הוא מסנן בזמן אמת ואלגוריתם זיהוי ראשוני; יש לכייל אותו על המכשיר הפיזי.
- מנוע הרטט והחומרה קובעים בפועל את עוצמת הרטט. לא בכל מכשיר יש שליטה רציפה בעוצמה.

## פתיחה ובנייה
1. התקן Android Studio עדכני עם Android SDK Platform 35.
2. פתח את התיקייה `VibraBeat` ב-Android Studio.
3. המתן ל-Gradle Sync.
4. חבר את Qin F21 Pro, הפעל USB debugging ובחר Run.
5. לחלופין: Build > Build Bundle(s) / APK(s) > Build APK(s).

## שימוש
1. פתח את VibraBeat.
2. בחר "שמע פנימי" או "מיקרופון".
3. אשר הרשאת הקלטה. בשמע פנימי אשר גם את חלון לכידת השמע של Android.
4. הפעל מוזיקה באפליקציה אחרת והשאר את VibraBeat בחזית.
5. כוון רגישות בס ועוצמת רטט מרבית לפי הצורך.
